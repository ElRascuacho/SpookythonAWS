# Arte de operaciones de campo

Fondos y sprite originales generados para este proyecto mediante ImageGen (2026-10-28).
Son representaciones ficticias inspiradas en Manta, no fotografía ni cartografía local.

- `quarantine.webp`: calle de contención para el shooter.
- `rooftops.webp`: fondo de ciudad para el parkour.
- `zombie.webp`: enemigo no gráfico con transparencia.
- `containment-rifle.webp`: manos y equipo de contención en primera persona.

Las imágenes se codificaron a WebP sin modificar su contenido. Se cargan únicamente
al entrar en el minijuego; si fallan, el visor conserva el escenario vectorial.
